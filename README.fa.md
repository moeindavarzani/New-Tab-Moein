## 🌟 ویژگی‌های برجسته

- 🎨 **طراحی شیشه‌ای و مدرن (Frosted Glass UI)**: ظاهر مات، شفاف و بسیار چشم‌نواز با استفاده از افکت بلور شیشه‌ای (`backdrop-filter`) متناسب با تم‌های روز وب.
- 🧭 **سربرگ یکپارچه و متقارن (Unified Header Bar)**: ترکیب لوگوی رنگی گوگل در راست، باکس جستجو در وسط و دسترسی ۲×۲ به حساب کاربری، جیمیل، تصاویر و اپلیکیشن‌های گوگل در چپ در یک خط افقی هماهنگ.
- 📁 **شبکه دسته‌بندی پوشه‌های نشانک‌ها**: نمایش تا ۱۲ پوشه مستقل برای موضوعات مختلف (هوش مصنوعی، سرویس‌های گوگل، شبکه‌های اجتماعی، برنامه‌نویسی، دانشگاه و پژوهش و...) در یک شبکه منظم ۴ ستونه.
- 🔀 **سازماندهی کامل با Drag & Drop**:
  - جابجایی کارت‌های پوشه با دستگیره گریپ ۶ نقطه‌ای (`⋮⋮`).
  - جابجایی ترتیبی نشانک‌ها درون یک پوشه یا انتقال آسان سایت‌ها میان پوشه‌های مختلف.
- 🎨 **چرخه رنگی و پالت هوشمند (Color Wheel)**: انتخاب رنگ پس‌زمینه اختصاصی برای هر پوشه با استفاده از چرخ رنگ HSL یا رنگ‌های ملایم پاستلی آماده.
- 🌐 **دریافت چندلایه و هوشمند آیکون‌ها (Smart Favicon Resolver)**: بهره‌گیری از API بومی نسخه ۳ کروم (`_favicon`) جهت استخراج مستقیم آیکون‌ها از کش محلی مرورگر (تضمین نمایش شفاف آیکون سایت‌های ایرانی، دانشگاهی، اینترانت ملی و سامانه‌های بانکی نظیر شاد، صیاد، مخابرات و...) به همراه زنجیره ۵ مرحله‌ای جایگزین (گوگل S2، دامنه‌های ریشه، داک‌داک‌گو، فایل مستقیم favicon.ico و کره زمین برداری).
- 🔖 **ورود مستقیم نشانک‌های مرورگر کروم**: امکان انتخاب و ایمپورت پوشه‌ها یا نشانک‌های مرورگر کروم با تیک زدن در یک پنجره منظم.
- 📶 **حالت آفلاین هوشمند با بررسی خودکار اتصال**:
  - نمایش کامل پوشه‌ها و دسترسی به نشانک‌ها حتی در زمان قطعی کامل اینترنت.
  - نمایش پیام انگلیسی در کادر میانی سربرگ: `No internet connection`.
  - بررسی خودکار وضعیت اینترنت هر ۲ ثانیه (تا سقف ۲۵ تلاش) و هدایت مستقیم به گوگل به محض برقراری اتصال.
  - عدم نمایش شمارنده تلاش در رابط کاربری جهت حفظ زیبایی و خلوت بودن صفحه.
- 📐 **چیدمان واکنش‌گرا و بهینه‌سازی اسکرول**: تغییر خودکار بین ۲ و ۳ ستون بر اساس عرض صفحه و حذف نوار اسکرول در کارت‌هایی که نشانک‌هایشان در ۲ ردیف جا می‌شوند.

## 💻 راهنمای نصب و راه‌اندازی

1. این ریپازیتوری را با دستور زیر دانلود یا کلون نمایید:
   ```bash
   git clone https://github.com/moeindavarzani/New-Tab-Moein.git
   ```
2. مرورگر **Google Chrome** را باز کنید و وارد صفحه زیر شوید:
   ```text
   chrome://extensions
   ```
3. کلید **Developer mode (حالت برنامه‌نویس)** در بالا سمت راست را فعال کنید.
4. روی دکمه **Load unpacked (بارگذاری بسته بازنشده)** کلیک نمایید.
5. پوشه پروژه را انتخاب کنید.
6. یک زبانه جدید باز کنید (`Ctrl + T`) تا رابط جدید و سفارشی گوگل را مشاهده فرمایید!

## 🏗️ ساختار فایل‌های پروژه

```text
New-Tab-Moein/
├── manifest.json       # تنظیمات افزونه Manifest V3 با دسترسی‌های tabs, bookmarks, storage, webNavigation
├── newtab.html         # صفحه زبانه جدید و کانتینر رابط کاربری آفلاین
├── redirect.js         # هدایت هوشمند آنلاین به گوگل / فعال‌کننده رابط آفلاین
├── background.js       # سرویس ورکر پس‌زمینه برای دسترسی به بوک‌مارک‌ها و مدیریت خطاهای شبکه
├── google_custom.js    # هسته اصلی: منطق پوشه‌ها، مودال‌ها، پالت رنگ، درگ اند دراپ و بررسی اتصال
├── google_custom.css   # استایل‌های شیشه‌ای، طراحی واکنش‌گرا، افکت‌ها و انیمیشن‌ها
├── icon128.png         # آیکون رسمی افزونه
├── test_logic.js       # مجموعه آزمون‌های واحد منطقی
└── test_runner.html    # مجموعه آزمون‌های ۲۵ گانه خودکار DOM در مرورگر هدلس کروم
```

## 🧪 تست‌های خودکار

برای اجرای کامل آزمون‌های منطقی و تست‌های DOM در مرورگر هدلس کروم:

```bash
node test_logic.js
```

تمامی ۱۵ بخش آزمون شامل ۲۵ تست مستقل در مرورگر Headless Chrome با موفقیت ۱۰۰٪ پاس می‌شوند.
